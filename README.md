# Projekt 1 – Task Manager

Projekt vznikl jako součást kurzu Engeto.

## Popis projektu

Jednoduchá konzolová aplikace pro správu úkolů.

Umožňuje:

- přidat nový úkol
- zobrazit všechny úkoly
- označit úkol jako splněný
- odstranit úkol

## Struktura projektu

- `projekt.py` – hlavní aplikace
- `test_cases.md` – testovací scénáře

## Spuštění

```bash
python projekt.py
```
